# Capstone Projects

Lessons teach pieces; projects prove you can build. Do them in order, and for each one
write the tests **first** where you can.

| # | Project | Skills it forces you to combine |
|---|---|---|
| 1 | [Contacts CLI](contacts-cli/README.md) | dataclasses, JSON persistence, argparse, error handling, unittest |
| 2 | Log analyser | file streaming, regex, `Counter`, generators, CLI reports |
| 3 | Mini text-adventure | classes, composition, state machines, `match` |
| 4 | CSV → report tool | `csv`, `statistics`, formatting, sorting with keys |
| 5 | Tiny HTTP JSON API client | `urllib`/`requests`, retries, typing, caching |
| 6 | Your own DSA library | packaging (`pyproject.toml`), imports, docs, 100% tested |

Only #1 ships with a full spec and test suite; the rest are deliberately open so you
practise designing from a blank file. Reuse the structure of project 1 for all of them.
