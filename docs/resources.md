# DSA Resources

Use these resources to deepen understanding after reading the repo notes. The repo should remain your central roadmap and mistake log.

---

## Practice platforms

- [LeetCode](https://leetcode.com/) - best for interview-style DSA practice.
- [HackerRank](https://www.hackerrank.com/) - beginner-friendly warmups and implementation practice.
- [Codeforces](https://codeforces.com/) - competitive programming and advanced problem solving.
- [AtCoder](https://atcoder.jp/) - excellent for fundamentals, DP, graphs, and math.
- [CSES Problem Set](https://cses.fi/problemset/) - structured algorithmic practice.

---

## Visual learning

- [VisuAlgo](https://visualgo.net/) - visualizes classic data structures and algorithms.
- [USFCA Data Structure Visualizations](https://www.cs.usfca.edu/~galles/visualization/Algorithms.html) - helpful animations for trees, heaps, graphs, and sorting.

## Reference material

- [Python official docs](https://docs.python.org/3/) - source of truth for Python language and standard library.
- [Python `collections`](https://docs.python.org/3/library/collections.html) - `Counter`, `defaultdict`, `deque`, `OrderedDict`.
- [Python `heapq`](https://docs.python.org/3/library/heapq.html) - heap / priority queue reference.
- [Python `bisect`](https://docs.python.org/3/library/bisect.html) - binary search helpers.
- [CP-Algorithms](https://cp-algorithms.com/) - advanced algorithms including graphs, strings, number theory, and data structures.

## Topic-specific suggestions

| Topic | Resource direction |
|---|---|
| Arrays/strings | Practice two pointers, windows, prefix sums daily until automatic. |
| Linked lists | Draw every pointer movement before coding. |
| Trees | Trace recursive return values, not just traversal order. |
| Graphs | Practice modeling: what are nodes, what are edges, what is the cost? |
| Dynamic programming | Write state meaning and recurrence before code. |
| Greedy | Do not trust intuition; write an exchange/stays-ahead proof. |
| Advanced strings | Learn KMP prefix table and Z algorithm by tracing small examples. |
| Segment tree/Fenwick | Implement from memory and test on tiny arrays. |

---

## How to avoid resource overload

1. Read this repo's topic guide first.
2. Watch/read one external explanation if the idea is unclear.
3. Implement the template yourself.
4. Solve 5-10 problems around the pattern.
5. Write mistakes in the tracker.
6. Move on; do not collect endless bookmarks.
