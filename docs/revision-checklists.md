# Revision Checklists

Use these lists before interviews or before moving to a harder topic.

---

## Core coding checklist

- [ ] I can write a clean function signature.
- [ ] I can handle empty input and one-element input.
- [ ] I can use `defaultdict`, `Counter`, `deque`, `heapq`, and `bisect`.
- [ ] I avoid `list.pop(0)` for queues.
- [ ] I avoid repeated string concatenation in loops.
- [ ] I can explain time and space complexity.
- [ ] I can produce at least three edge cases before running code.

---

## Arrays and strings

- [ ] Two pointers on sorted arrays.
- [ ] Sliding window fixed size.
- [ ] Sliding window variable size.
- [ ] Prefix sum and prefix count map.
- [ ] Kadane's algorithm.
- [ ] Matrix boundary traversal.

---

## Linked lists

- [ ] Reverse list iteratively.
- [ ] Use dummy node for deletion/merge.
- [ ] Detect cycle with fast/slow pointers.
- [ ] Find middle node.
- [ ] Merge two sorted lists.
- [ ] Reverse nodes in k-group conceptually.

---

## Stacks and queues

- [ ] Valid parentheses.
- [ ] Monotonic decreasing stack.
- [ ] Monotonic increasing stack.
- [ ] Monotonic deque for sliding max/min.
- [ ] Queue BFS by levels.

---

## Binary search

- [ ] Standard exact search.
- [ ] Lower bound.
- [ ] Upper bound.
- [ ] Rotated sorted array.
- [ ] Binary search on answer.
- [ ] Explain monotonic feasibility.

---

## Trees

- [ ] Recursive preorder/inorder/postorder.
- [ ] Iterative traversal.
- [ ] BFS level order.
- [ ] Diameter/max path patterns.
- [ ] Lowest common ancestor.
- [ ] Serialize/deserialize.
- [ ] Validate BST.

---

## Graphs

- [ ] Build adjacency list.
- [ ] DFS connected components.
- [ ] BFS shortest path.
- [ ] Topological sort by indegree.
- [ ] Detect cycle directed/undirected.
- [ ] Dijkstra.
- [ ] Union Find.

---

## Dynamic programming

- [ ] Define state in one sentence.
- [ ] Write recurrence.
- [ ] Identify base cases.
- [ ] Choose computation order.
- [ ] Explain memoization vs tabulation.
- [ ] Compress space when safe.
- [ ] Recognize knapsack, LIS, LCS, interval DP, bitmask DP.

---

## Advanced

- [ ] Trie insertion/search/prefix.
- [ ] Fenwick update/query.
- [ ] Segment tree query/update.
- [ ] KMP prefix table.
- [ ] Z algorithm purpose.
- [ ] Bitmask subset enumeration.
- [ ] MST with Kruskal.
- [ ] Tarjan bridges.
- [ ] LRU cache design.
