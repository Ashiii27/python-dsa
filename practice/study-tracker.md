## Mistake taxonomy

Use these labels in the problem log:

- **Pattern**: did not recognize the right approach.
- **Bug**: implementation issue, off-by-one, wrong variable update.
- **Edge**: failed on empty, duplicate, negative, cycle, disconnected, etc.
- **Complexity**: solution too slow or memory-heavy.
- **Proof**: could code but could not explain why it works.
- **Python**: language-specific issue such as slicing, heap tuple, recursion depth.
