# Company-Style Preparation Sheets

These are not company-specific leaked lists. They are style-based practice sets that reflect the kinds of skills commonly tested by top-tier interview loops.

---

## Big Tech generalist loop

Focus:

- arrays/strings and hashing
- binary search
- trees
- graphs
- dynamic programming
- design data structures

Practice set:

1. Two Sum
2. Product of Array Except Self
3. Minimum Window Substring
4. Search in Rotated Sorted Array
5. Binary Tree Maximum Path Sum
6. Serialize and Deserialize Binary Tree
7. Course Schedule
8. Word Ladder
9. Coin Change
10. Edit Distance
11. LRU Cache
12. Insert Delete GetRandom O(1)

---

## Mock interview rotation

Use this 5-round rotation:

1. Arrays/hashmap medium + tree medium
2. Binary search medium + graph medium
3. Heap/interval medium + design medium
4. DP medium + backtracking medium
5. Hard problem from DP, graph, strings, or data structures

After each mock, update `study-tracker.md` with the mistake type and redo date.
